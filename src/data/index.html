Saved networks

    No networks saved. The pad stays in access point mode until you add one.

    On boot the pad scans, then tries these in order against whatever is in range. Up to 10 networks. If none connect it opens its own access point and restarts every hour until it gets online.

    Screens

    The knob push button steps through the enabled screens, then an info screen showing the network and address, then back to the first. Disabled slots are skipped.

    Time comes from NTP once the pad is online. The zone rule includes daylight saving, so the clock corrects itself.

    Keep it at or under 320x206 pixels so it fits below the header. Large GIFs decode slowly and eat the filesystem.

    The calculator uses this screen's key bindings. The numeric keypad keys drive it, as do plain 0-9, ., +, -, *, /, =, ESC and BACKSPACE. Num Lock clears and Numpad Enter evaluates. Those keys are handled on the pad and never reach the host; anything else stays a normal macro key.

    Key bindings for this screen

    Laid out like the pad itself. Each screen has its own map. Click a key to pick from every binding the pad understands: letters, digits, punctuation, F1-F24, navigation and editing keys, media keys, and modifier combinations. Press a key on the pad to highlight it here. The knob push button sits under the double height + and is not shown, since it cycles screens rather than sending a key.

    Device

    The screen change key cycles through enabled screens and is never sent to the host. Default is key 11, the knob push button.

    Bluetooth keyboard

    Name and on/off changes take effect after a reboot.

    Knob rotation

    Rotation is global, it does not change with the screen.

    Storage

    -

    Reset restores the factory configuration, including the numeric keypad key bindings. It also clears the saved WiFi networks, so the pad will come back up as an access point. The stored configuration always wins over the built-in defaults, so this is the only way to pick up a default keymap that changed in a firmware update.
